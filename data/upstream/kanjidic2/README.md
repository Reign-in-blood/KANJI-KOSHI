# KANJIDIC2 French meanings snapshot

This directory contains a filtered French-meaning snapshot derived from KANJIDIC2 data exposed by `jkindrix/japanese-language-data`.

- Intermediary repository: jkindrix/japanese-language-data
- Revision: `04014e06019fc9d4af76e6dbb64ec709fe863c4d`
- Upstream dictionary: KANJIDIC2 / EDRDG
- License: CC BY-SA 4.0
- OpenJLPT target kanji: 2211
- Kanji with French meanings: 1992 (90.09%)

Only French meanings for kanji currently present in the KANJI KŌSHI OpenJLPT snapshot are stored here.

The missing 219 entries keep English meanings from OpenJLPT and use English as the runtime fallback until another compatible French source is added.

Do not edit `fr-meanings.json` by hand. Refresh it with `npm run sync:kanjidic2-fr`, then rebuild generated data.
